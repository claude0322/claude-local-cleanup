# CC Switch 单独审阅

CC Switch 同时管理多个工具的供应商和代理配置，并非 Claude 官方登录状态的一部分。本项目不附自动修改其数据库的脚本。

用户要求处理时：

1. 在应用中确认 Claude 供应商、路由及启用状态，不显示 API key。
2. 列出要移除的具体配置与代理影响，默认保留 Codex、Gemini 等其他工具。
3. 创建留在本机的受限备份，说明恢复方式，取得此清单授权。
4. 优先使用应用支持的操作，完成后检查其他工具配置未变。

不删除整个 `.cc-switch`，不猜测数据库 schema 执行 SQL，不清空混合历史和备份。界面不足以完成时说明未完成项。
